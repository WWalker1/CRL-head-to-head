01 / REPRESENTATION

A card is a learned vector.

“Zap : Evolution” has its own canonical key and embedding. Levels and elixir features are projected into that same 64-number space. These numbers are learned from outcomes, not handcrafted damage statistics.

02 / ATTENTION

Query. Key. Value.

Each card asks a question with a query. It compares that query with other cards’ keys, then mixes their values using the resulting weights. Four heads learn four ways of making that comparison.

03 / LEARNING

Errors change the weights.

The predicted probability is compared with the winner. Backpropagation adjusts embeddings and attention weights. More recent training games receive greater weight; unseen later games measure generalization.

The experiment, exactly

What this result does—and doesn’t—tell us

The model predicts outcomes among recent UC players. It cannot see timing, starting hand, execution or familiarity with a deck. It has not been evaluated on Grand Champion, draft, new patches or entirely new cards. This is an initial experiment, not a production recommendation engine.

Attention weights are associations. A deck that receives a high score is not necessarily a proven counter. Compare against baselines and inspect calibration before trusting the number.
