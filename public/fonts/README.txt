Rival Sans and Rival Mono are Latin subsets of IBM Plex Sans and IBM Plex Mono, renamed to respect the reserved font names. Original copyright and SIL Open Font License notices are included alongside these files. Sources: github.com/google/fonts/tree/main/ofl/ibmplexsans and github.com/google/fonts/tree/main/ofl/ibmplexmono. Generated with fontTools, WOFF2 compression, Latin + punctuation + arrows. CSS falls back to system fonts for other characters.
